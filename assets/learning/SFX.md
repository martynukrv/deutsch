# Optional action sounds

Seven fixed MP3 files in `audio/sfx/20261025` serve button clicks, new clue fragments, passed-lesson seals, boat departure, lighthouse activation, correct answers and gentle try-again feedback. Sources and provenance are in `audio-sources/sfx-20261025`; `scripts/prepare_sfx.py` reproduces the five deterministic DSP cues and normalizes all seven to a -10 dBFS peak before quiet in-app volume scaling. The click and clue originals were generated with ElevenLabs Sound Effects v2. The remaining five use original DSP synthesis because ElevenLabs rejected further unstarted jobs with HTTP 429. They are not represented as AI-generated clips.

The independent “Звуки ефектів” / “Effects” control is always available next to profiles. `deutsch16_sfx_v1` is profile-scoped. Effects never start before a user gesture, and play failures (including autoplay rejection) are silent. Only one effect player runs; its short queue is bounded, expires in five seconds and discards detached reward owners. Navigation, hidden tabs, speech and microphone start stop the player and clear the queue. Stale play promises cannot cancel a newer effect.

The existing global speech entry point provides voice priority. Listen-and-repeat marks its own original-recording playback as voice too. SpeechRecognition constructors are wrapped only to count active recognition sessions; their event/result behavior is retained. Effects are suppressed while recording, including aborted/error sessions. No student recordings are stored or sent by the SFX module.

The old oscillator tone is disabled. Existing graded flows already route through `DEUTSCH_FLOW.feedback`: the generated correct/incorrect cue plays after the original German sample finishes, within the existing two-second advance pause. No extra wait or grading change is introduced. Listen-and-repeat uses its existing one-second feedback interval. Newly visible clue rewards and lesson seals use visibility-triggered one-shot cues. Story scenes start their matching effect when the scene opens and stop it on skip/close; no ambient map loop is added, and the previously rejected map-particle animations remain disabled.

Tests: `.github/tests/sfx.cjs` checks gesture gating, speech/microphone priority and release, mute persistence, cancellation, responsive/localized controls and real browser metadata decoding of every MP3. The existing shadowing audio fake distinguishes SFX playbacks from original German samples while still detecting audio overlapping a microphone start. All prior route, audio, grading and profile regressions remain enabled.

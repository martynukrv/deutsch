# Слухай і повторюй / Listen and repeat

Independent, optional mode in the 15 vocabulary/grammar lessons across both islands. The Karl dialogue lesson, live conversations and final missions are excluded. Training and exam unlocks, scores, seals, SRS and route progress are unchanged.

Each run shuffles all lesson phrases. Each phrase has **three consecutive audio → learner reply cycles**, with one original whole recording before each reply. After each result, a one-second feedback interval leads into the next cycle; there is no extra correct-answer recording after a reply. Only after the third reply does the next phrase begin. Six phrases therefore give 18 opportunities to speak and 18 sample playbacks. The UI shows both phrase progress and repeat 1/3, 2/3, 3/3. No TTS fallback, token composition or new recording is used.

The microphone opens after sample playback ends. A five-second timer starts when recognition starts and is cancelled when speech begins (including interim results). The system waits for the utterance to finish; a 30-second service watchdog prevents stuck sessions. Silence or an explicit skip consumes only the current repeat; the remaining repeats of that phrase still run. Audio, microphone and network failures allow retrying the same repeat without consuming it. Pausing after a recorded result resumes at the next repeat, so no answer is counted twice.

This change is confined to this mode. Training, tests, dialogues and their existing correct-answer playback/pacing are untouched.

This version checks the recognised German transcript, ignoring punctuation/case and curly versus straight apostrophes. Recognition alternatives are accepted for a single final result. It does **not** measure phonetic accuracy or accent. Browser confidence is explicitly labelled “Достовірність розпізнавання”, never “pronunciation percentage”. The summary percentage is recognised repeats divided by spoken replies, excluding silence and skips; zero replies displays a dash. Proper phonetic scores require a separately configured pronunciation-assessment backend, which is not present in this static app.

Silence is skipped, permission/network/audio failures show recovery controls and do not count as wrong answers. Pause, hidden-tab handling, lesson exit, island selection and tab navigation stop the microphone, playback and pending timers. Resume restarts the interrupted phrase, or advances to the next repeat if its result was already recorded. Original audio failure pauses instead of silently synthesising speech.

The completed summary stores the latest run per stable lesson id (`0:greetings`, `0:0`…`0:7`, `1:courtesy`, `1:0`…`1:4`) in profile-scoped `deutsch16_listen_repeat_v1`. Version 2 records total repeats (18 for six phrases), phrase count, recognised/attempted/skipped repeats, each reply’s repeat number, transcripts/confidence and elapsed seconds. Existing records remain isolated under the same key; a new run replaces only that lesson’s latest summary. Recordings of the learner are not stored by the app; the browser recognition provider may process microphone audio online, as explained before starting. “Repeat difficult phrases” includes each phrase with any wrong, unrecognised, silent or skipped repeat once, and gives it all three audio/reply cycles again. “Repeat all” restores the original lesson batch.

Browser regression: `.github/tests/shadowing.cjs` checks every eligible lesson, exclusions, playback ordering, microphone timings, recovery, cancellation, unchanged grades, localization, responsive layouts and profile isolation. Recognition/audio lifecycle uses deterministic browser fakes; real microphone permissions and recognition quality must also be checked on the target device.

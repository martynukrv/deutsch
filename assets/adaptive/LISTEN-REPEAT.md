# Слухай і повторюй / Listen and repeat

Independent, optional mode in the 15 vocabulary/grammar lessons across both islands. The Karl dialogue lesson, live conversations and final missions are excluded. Training and exam unlocks, scores, seals, SRS and route progress are unchanged.

Each run shuffles all lesson phrases. A phrase plays three times from its **original whole recording**, with 400 ms between models. There is no TTS fallback, token composition or new recording. The microphone opens after playback ends. A five-second timer starts when recognition starts, and is cancelled when speech begins (including interim results). The system waits for the utterance to finish; a 30-second service watchdog prevents stuck sessions. Result feedback lasts one second, then the original model plays once more and the next phrase starts automatically.

This version checks the recognised German transcript, ignoring punctuation/case and curly versus straight apostrophes. Recognition alternatives are accepted for a single final result. It does **not** measure phonetic accuracy or accent. Browser confidence is explicitly labelled “Достовірність розпізнавання”, never “pronunciation percentage”. The summary percentage is recognised phrases divided by spoken replies, excluding silence and skips; zero replies displays a dash. Proper phonetic scores require a separately configured pronunciation-assessment backend, which is not present in this static app.

Silence is skipped, permission/network/audio failures show recovery controls and do not count as wrong answers. Pause, hidden-tab handling, lesson exit, island selection and tab navigation stop the microphone, playback and pending timers. Resume restarts the interrupted phrase, or advances if its result was already recorded. Original audio failure pauses instead of silently synthesising speech.

The completed summary stores the latest run per stable lesson id (`0:greetings`, `0:0`…`0:7`, `1:courtesy`, `1:0`…`1:4`) in profile-scoped `deutsch16_listen_repeat_v1`. It records recognised, attempted, skipped, per-phrase transcripts/confidence and elapsed seconds. Recordings of the learner are not stored by the app; the browser recognition provider may process microphone audio online, as explained before starting. “Repeat difficult phrases” includes wrong, unrecognised, silent and skipped phrases. “Repeat all” restores the original lesson batch.

Browser regression: `.github/tests/shadowing.cjs` checks every eligible lesson, exclusions, playback ordering, microphone timings, recovery, cancellation, unchanged grades, localization, responsive layouts and profile isolation. Recognition/audio lifecycle uses deterministic browser fakes; real microphone permissions and recognition quality must also be checked on the target device.

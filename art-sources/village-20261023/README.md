# Знайомство з мешканцями — другий острів

Шість уроків по шість карток: sein, haben, запитання, nicht / kein, знайомство та діалоги. Окремий тест після кожного уроку, фінальна місія з 18 різних фраз (по три з кожного уроку). Діалогові завдання просять відповідати німецькою від імені персонажа Олексія. 30 різних фраз з наявного курсу, для кожної є цілісний запис вимови.

Обидва острови відкриті. Прогрес першого залишається в `deutsch16_journey_v1` без міграції; другий використовує `deutsch16_journey_village_v1`. Вибір острова зберігається окремо. Усе ізольовано за профілем. 80% фіналу дає артефакт, 100% — печатку першовідкривача. Невдале повторення не забирає нагород. Спільна колекція показує компас і ключ від маяка.

Ілюстрації створені вбудованим imagegen. Арт-напрям: проста дружня графіка з товстими органічними контурами, палітра #102B50 / #FF5726 / #FFFFFF / #FFF1E5, характерні короткі штрихи. Мапа йде зверху вниз через причал, ринок, площу, браму, будинок знайомств, дім хранителя до маяка. Ключ має силует маяка в круглій голівці. Сцени речень показують правильну особу, кількість людей, місце, стан, питання або заперечення.

Збережені сім оригіналів PNG, таблиця точних прив’язок та перевірені межі вирізання. Обробка — лише вирізання, прозорі поля, зменшення й WebP-стиснення. 30 окремих сцен + мапа + ключ. Сусідні фрагменти виключені індивідуальними межами. Попередні ілюстрації збережені.

Тести: `.github/tests/village.cjs` та `.github/tests/native-scenes.cjs`, також виконуються на опублікованому сайті. Локальна модель перевіряє 2 000 фінальних черг без повторів, збереження першого острова, нагород, діалогів та ізоляції записів.

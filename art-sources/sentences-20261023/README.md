# Аудит ілюстрацій речень — 23.10.2026

Перевірено весь адаптивний маршрут: 11 тем, з них 8 уроків на мапі. 46 різних фраз не мали власної сцени: використовували зображення інфінітива.

## Оригінали й обробка

Джерело: вбудований imagegen, по шість сцен на аркуші. Оригінали та точні промпти збережено поряд. `crop-plan.json` фіксує перевірені межі вирізання. Обробка лише вирізання, прозорі поля та стиснення у WebP; без перемальовування скриптами. Власні сцени мають пріоритет перед попереднім тематичним підбором. Прив’язка за точним німецьким реченням та значенням українською, не за позицією картки.
